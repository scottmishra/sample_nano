# Web Research

When the user asks for research on a topic:

1. Use brave-search to find recent news, articles, and documentation on the topic
2. Use brave-search with different query angles to get broad coverage:
   - Industry news and announcements
   - Technical documentation and best practices
   - Competitive landscape and benchmarks
3. Cross-reference findings with known context:
   - For supply chain topics: reference Univar Solutions, DOW Chemical pilot, Sensium optimization platform
   - For Azure topics: reference existing infrastructure and compliance posture
   - For AI topics: reference Claude Agent SDK, NanoClaw architecture
4. Summarize with:
   - Key findings (bulleted, with source links)
   - Relevance to Sensium's work
   - Recommended actions or follow-ups
   - Confidence level (high / medium / low) based on source quality
